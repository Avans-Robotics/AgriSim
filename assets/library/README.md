# Asset Library

Committed Variants per Crop, one folder per Crop (`carrot/`, ...) with `.glb` files (root crops also have `<variant>.physics.json` and `<variant>.articulated.glb` for pull-out, ADR 0006), plus shared `textures/`: CC0 soil sources (`soil/`, `soil_dry/`) and the baked soil atlas the Exporter uses (`soil_tiles/`, from `generators/soil.py`). Imported third-party assets carry an `ATTRIBUTION.md` in their folder. See ADR 0003 and ADR 0004.
