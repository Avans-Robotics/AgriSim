# examples

Example Field Specs, hand-drawn and random. Format: see section 5 of `docs/design/spec.md`.

`avans_kas.yaml` is the agrobot competition bed in the Avans greenhouse: 3 x 8 Pixels of 0.9 m, one Crop each, Path Gaps for the Amiga straddling one Pixel column, and a Venue (paver floor, glass greenhouse) around it. The greenhouse size is a rough guess.

`amiga_10x10.yaml` is a Field for the Farm-ng Amiga: Path Gaps that fit its 1.524 m wheel track and a 2 m Border to drive on. The Manifest lists the x range of each gap (`field.path_gaps`).
